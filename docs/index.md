## About This Project

The [College Document Archive System](https://github.com/arthiccc/archive-system) is a web-based document management system built with:

- **Python 3.13** + Flask 3.1.2
- **PostgreSQL 17.7** for data storage
- **Redis 7.4.7** for caching
- **Docker** for containerization

Try it live: [Open in GitHub Codespaces](https://codespaces.new/arthiccc/archive-system)
